# AgriOS brand kit

Everything here is generated by `python scripts/brand/build_brand.py` from
`source/logo-composite.jpg` (the approved logo sheet). Emblem and icon are
clean vector geometry measured from that sheet; the wordmark is traced from
it, so it carries the real letterforms but not the font.

## Colours (sampled from the artwork)

| Role | Hex |
|---|---|
| Emerald (left plane, primary action) | `#239B6D` |
| Deep emerald (right plane, brackets, secondary fills) | `#33644C` |
| Tile / card (warm near-black) | `#1C1813` |
| Cream (light background, text on dark) | `#F2EAD8` |
| Ink (text on light) | `#1E1811` |

## Files

| File | Use |
|---|---|
| `emblem.svg`, `emblem-*.png` | Two-tone emblem, transparent background, 16 to 1024 px |
| `emblem-mono.svg`, `emblem-mono-*.png` | Single-colour emblem (`currentColor` in the SVG; emerald, white and ink PNGs) |
| `app-icon.svg`, `app-icon-rounded-1024.png` | Presentation icon with rounded tile and scan brackets |
| `wordmark.svg`, `wordmark-*.png` | "AgriOS" for light backgrounds |
| `wordmark-on-dark.svg`, `wordmark-on-dark-*.png` | "AgriOS" in cream for dark backgrounds |
| `lockup-light.*`, `lockup-dark.*` | Icon + wordmark lockups |
| `emblem-geometry.json` | Path data used by the in-app `Emblem` component |

The platform assets in `assets/` (`icon.png`, `adaptive-icon.png`,
`adaptive-icon-mono.png`, `splash-icon.png`) come from the same script.
`icon.png` is a full square; iOS applies its own mask. The adaptive
foreground keeps the emblem inside the Android safe zone.
